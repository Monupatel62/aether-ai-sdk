# Research and Licenses — aether-ai-sdk

## Evaluation areas
- OpenAPI-generated client vs. handwritten typed client.
- HTTP transport support, cancellation, browser/server runtime compatibility, and bundle size.
- Semantic versioning, deprecation, and generated-code license implications.

## Review requirements
Before adding a dependency, record exact package/version, license, transitive dependencies, security advisories, maintenance status, and reason it is needed. Generated files must retain required notices.
